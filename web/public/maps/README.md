# Cartografía opcional

Para habilitar el mapa geográfico, incorporar `ecuador_provincias.geojson` con
24 provincias, propiedad `codigo_provincia` (01–24) y geometría Polygon o
MultiPolygon en longitud/latitud WGS84 verificada. La API asigna los nombres
canónicos por código. Documentar fuente, licencia,
fecha y versión de límites antes de utilizarlo en el artículo.

La matriz de calor funciona sin este archivo. No se descargan mapas de terceros
silenciosamente ni se imputan coordenadas para dibujar concentraciones.
